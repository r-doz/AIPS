\paragraph{GNN.}
This baseline is a graph convolutional network (GCN)~\citep{kipf2017semi} defined on the grid: each cell is a node, and edges connect cells that share an edge or a corner (queen contiguity). Each day is treated as a separate graph with the same structure, whose node features are the cell coordinates, the position of the day within the year, the covariates of the target day and the counts observed in the same cell one and seven days earlier, all standardized with training statistics. Each graph-convolution layer updates the representation of every node by aggregating the linearly transformed features of the node itself and of its neighbors, followed by a ReLU activation. We use one such layer with 64 hidden features and dropout of $0.1$, followed by a node-wise linear output layer with a softplus activation that returns the Poisson rate $\widehat{\lambda}_{j,t}$ of each cell. The network is trained by minimizing the mean Poisson negative log-likelihood over all cells and training days, using full-batch Adam with learning rate $10^{-1}$ and weight decay $10^{-5}$ for 300 epochs. The number of layers, the hidden dimension and the learning rate were selected on the validation weeks (App.~\ref{app:hyperparameters}). During evaluation, the lagged counts of each test day are the counts observed on the preceding days.
